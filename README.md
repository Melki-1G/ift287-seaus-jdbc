English
Overview

This project was developed for the IFT287 course (Database Systems) at Université de Sherbrooke.

The application is a Java JDBC system designed to manage Indigenous water infrastructure projects in Canada.

The system manages:

Communities
Companies
Water infrastructure projects
Parent company relationships

The application uses a 3-tier architecture:

Data layer (tables)
Business/transaction layer (gestion)
Data object layer (tuples)
Technologies Used
Java
JDBC
PostgreSQL
SQL
Git & GitHub
IntelliJ IDEA
Main Features
Add, edit, delete and display communities
Add, edit, delete and display companies
Add, edit, delete and display projects
List projects associated with a community
List projects associated with a company
Manage parent company relationships
SQL transaction management with commit and rollback

Aperçu

Ce projet a été réalisé dans le cadre du cours IFT287 (Systèmes de bases de données) à l’Université de Sherbrooke.

L’application est un système Java JDBC conçu pour gérer des projets d’infrastructures d’eau potable dans les communautés autochtones du Canada.

Le système permet de gérer :

Les communautés
Les compagnies
Les projets d’infrastructure
Les relations de compagnies parentes

L’application utilise une architecture à 3 couches :

Couche données (tables)
Couche traitement/gestion (gestion)
Couche objets de données (tuples)
Technologies utilisées
Java
JDBC
PostgreSQL
SQL
Git & GitHub
IntelliJ IDEA
Fonctionnalités principales
Ajouter, modifier, supprimer et afficher des communautés
Ajouter, modifier, supprimer et afficher des compagnies
Ajouter, modifier, supprimer et afficher des projets
Lister les projets d’une communauté
Lister les projets d’une compagnie
Gérer les relations de compagnies parentes
Gestion des transactions SQL avec commit et rollback
