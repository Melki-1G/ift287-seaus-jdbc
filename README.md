# ift287-seaus-jdbc
University JDBC project using Java, PostgreSQL and SQL transactions with a 3-tier architecture.

# IFT287 - SeauS JDBC Project / Projet JDBC SeauS

## English

### Overview

This project was developed for the IFT287 course (Database Systems) at Université de Sherbrooke.

The application is a Java JDBC system designed to manage Indigenous water infrastructure projects in Canada.

The system manages:

- Communities
- Companies
- Water infrastructure projects
- Parent company relationships

The project follows a 3-tier architecture:

- Transaction layer (`gestion`)
- Data access layer (`tables`)
- Data transfer objects (`tuples`)

---

### Technologies

- Java
- JDBC
- PostgreSQL
- SQL
- IntelliJ IDEA

---

### Features

- Add / edit / delete projects
- Manage communities and companies
- Track project progress
- Manage parent company relationships
- SQL transaction management (`commit` / `rollback`)
- JDBC with `PreparedStatement` and `ResultSet`

---

### Educational Concepts

This project demonstrates:

- JDBC programming
- CRUD operations
- SQL transactions
- 3-tier software architecture
- Object-oriented programming
- Relational database integration

## Français

### Présentation

Ce projet a été développé dans le cadre du cours IFT287 (Systèmes de bases de données) à l’Université de Sherbrooke.

L’application est un système Java JDBC permettant de gérer des projets d’infrastructures d’eau potable dans des communautés autochtones du Canada.

Le système permet de gérer :

- Les communautés
- Les compagnies
- Les projets d’infrastructure
- Les relations entre compagnies parentes

Le projet suit une architecture 3 couches :

- Couche transaction (`gestion`)
- Couche accès aux données (`tables`)
- Couche objets de transfert (`tuples`)

---

### Technologies utilisées

- Java
- JDBC
- PostgreSQL
- SQL
- IntelliJ IDEA

---

### Fonctionnalités

- Ajouter / modifier / supprimer des projets
- Gérer les communautés et les compagnies
- Suivre l’état d’avancement des projets
- Gérer les relations entre compagnies parentes
- Gestion des transactions SQL (`commit` / `rollback`)
- Utilisation de JDBC avec `PreparedStatement` et `ResultSet`

---

### Concepts appris

Ce projet démontre :

- La programmation JDBC
- Les opérations CRUD
- Les transactions SQL
- L’architecture logicielle 3 couches
- La programmation orientée objet
- L’intégration avec une base de données relationnelle
